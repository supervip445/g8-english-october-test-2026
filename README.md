# Grade 8 English October Test — Units 4–7

Static HTML/CSS/JS study site, ready for Vercel.

## Deploy
1. Upload this folder to a GitHub repository.
2. In Vercel, import the repository.
3. Framework Preset: Other / static.
4. Build Command: leave empty.
5. Output Directory: `.`
6. Deploy.

## Copy / screenshot protection
The site disables text selection, copy/cut, right-click, common save/print/view-source shortcuts, and hides content briefly when the page loses visibility. **No normal website can reliably prevent OS-level screenshots or a user photographing the screen.** For stronger protection, use server-side authentication and serve answers only after authorization; even then screenshots cannot be technically guaranteed to be impossible.
